## 주요 기능

### 1. 채용 공고 목록
- 채용 회사 및 공고 목록 조회
- 채용 공고 상세 페이지 조회
- 회사명과 공고명을 클릭하여 상세 정보 확인

### 2. 채용 공고 검색
- 검색 조건을 선택하여 채용공고 검색
- 전체 검색 지원
- 회사명 검색
- 공고명 검색
- 경력 검색
- 고용형태 검색
- 지역 검색
- 모집직무 검색
- 검색 결과가 없는 경우 안내 화면 표시

### 3. 지원 관리
- 채용 공고 지원
- 지원 취소
- 지원한 채용공고 목록 조회
- React `useState`를 이용한 지원 상태 관리
- 지원/취소 시 변경된 상태를 화면에 즉시 반영

### 4. 찜 관리
- 관심 채용공고 찜
- 찜 취소
- 찜한 채용공고 목록 조회
- React `useState`를 이용한 찜 상태 관리
- 찜/취소 시 변경된 상태를 화면에 즉시 반영

### 5. 이력서 관리
- 지원한 채용공고에 이력서 제출
- 이력서 제출 취소
- 이력서 제출 전 확인 메시지 제공

### 6. 메모 관리
- 지원한 채용공고에 메모 등록
- 기존 메모 수정
- 메모 삭제
